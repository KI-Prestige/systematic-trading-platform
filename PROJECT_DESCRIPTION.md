# Systematic Trading Platform – Portfolio Project

**Role demonstrated:** Junior Quant Developer / Systematic Trader

Built a complete end-to-end systematic trading platform in Python with the following features:

- Designed and implemented a modular architecture with clear separation of concerns (data, strategy, risk, execution, monitoring).
- Developed a robust data pipeline using yfinance and SQLite caching for efficient market data handling.
- Created a risk-managed backtester supporting SMA crossover strategy with transaction costs, volatility-targeted position sizing, Sharpe ratio, and maximum drawdown calculation.
- Built a signal generator that converts backtest logic into actionable buy/sell/hold signals.
- Integrated Alpaca paper trading API with safe, position-aware order execution and order logging.
- Added an interactive Streamlit dashboard showing backtest results, live signals, current paper positions, and trade history.
- Maintained professional development practices: Git version control, virtual environments, and comprehensive README.

**Technical Stack:** Python, pandas, yfinance, sqlite3, alpaca-py, streamlit

**Key Learning:** Emphasis on robustness, risk management, and production readiness rather than complex models. Currently running daily paper trading to build performance track record.

This project demonstrates practical skills required for systematic trading and quant development roles: reliable infrastructure, risk awareness, execution, and monitoring.
